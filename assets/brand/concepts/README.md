# BetterTTS visual concept archive

This folder preserves the five original identity directions created during the BetterTTS v0.25.0 marketing pass.

- `direction-02-selected-ribbon-wave.png` is the approved direction.
- `selection.json` is the machine-readable selection record.
- `../bettertts-selected-master.png` is an untouched copy of the approved source.
- Product-ready size variants remain in the parent `assets/brand` folder.

Keep these files with the repository so the design history and selected identity remain verifiable.
